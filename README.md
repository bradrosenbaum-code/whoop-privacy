# Privacy Policy — Personal WHOOP Integration

**Effective date:** September 30, 2026

## What this is

This is a personal, single-user integration between a WHOOP account and a private training-data repository. It exists solely for the WHOOP account holder's own training analysis. It is not a commercial product and has no other users.

## Data collected

With the account holder's explicit OAuth authorization, the integration reads from their own WHOOP account only:

- Workout data (activity type, date, duration, heart rate, strain, calories, heart-rate zone durations)
- Sleep, recovery, resting heart rate, and heart-rate variability (HRV)

No data is collected from anyone else. Only read access is requested; the integration never modifies WHOOP data.

## How data is used and stored

Data is written to a private GitHub repository controlled by the account holder, used as a personal training log. Data is not shared with, sold to, or disclosed to any third party. There is no advertising, analytics, or cross-site tracking.

## Data retention and deletion

Data remains in the account holder's private repository until they delete it. Revoking the integration's access in WHOOP settings stops all future data collection immediately.
